## 方案一：Schemdraw（最推荐）

[Schemdraw](https://schemdraw.readthedocs.io/) 是一个 Python 库，用代码描述电路，直接输出 SVG。**最适合你的场景**——电路分析笔记里最常见的电阻、电容、电感、运放、受控源它都能画。

### 示例

```python
import schemdraw
import schemdraw.elements as elm

with schemdraw.Drawing() as d:
    d += elm.Battery().label('$V_s$')
    d += elm.Resistor().label('$R_1$')
    d += elm.Line().down()
    d += elm.Line().left()
```

一条命令导出 SVG：

```bash
python circuit.py > output.svg
```

### 集成到 MkDocs

在 `mkdocs.yml` 同级写一个 `gen_circuits.py`，扫描 `docs/` 下的 `.py` 文件批量生成 SVG，然后 `mkdocs build` 前执行：

```bash
python gen_circuits.py && mkdocs build
```

### 优点
- 语法直观，接近手绘习惯
- 输出矢量 SVG，无限缩放
- 支持 LaTeX 数学标签（和你的 MathJax 完美配合）

```
"""

from pathlib import Path

import schemdraw
import schemdraw.elements as elm
from schemdraw import Drawing

OUTPUT_DIR = Path(__file__).parent.parent / "docs" / "assets" / "circuits"
OUTPUT_DIR.mkdir(parents=True, exist_ok=True)


def fig_4_5_1_two_voltage_sources_series():
    """两电压源串联"""
    d = Drawing(show=False)
    d += (V1 := elm.Battery().up().label("$V_{s1}$").length(4))
    d += elm.Battery().up().label("$V_{s2}$").length(4)
    d += elm.Line().right().length(2)
    d += elm.Line().down().length(8)
    d += elm.Line().left().length(2)
    d.save(OUTPUT_DIR / "4_5_1_voltage_series.svg")
    return d


def fig_4_5_2_two_voltage_sources_parallel():
    """两电压源并联"""
    d = Drawing(show=False)
    # 上支路
    d += elm.Battery().right().label("$V_{s1}$").length(4)
    d.push()
    # 下支路
    d += elm.Line().down().length(3)
    d += elm.Battery().right().label("$V_{s2}$").length(4)
    d += elm.Line().up().length(3)
    d.pop()
    d.save(OUTPUT_DIR / "4_5_2_voltage_parallel.svg")
    return d


def fig_4_5_3_two_current_sources_parallel():
    """两电流源并联"""
    d = Drawing(show=False)

    # 下支路
    d += elm.Line().down().length(3)
    d += elm.SourceI().right().label("$I_{s2}$").length(4)
    d += elm.Line().up().length(3)
    d.pop()
    d.save(OUTPUT_DIR / "4_5_3_current_parallel.svg")
    return d

    d += elm.Resistor().right().label("$R_1$").length(4)
```

```
#!/usr/bin/env python3
"""
批量生成所有电路图 SVG。

用法:
    python gen_circuits.py          # 生成所有
    python gen_circuits.py --dry    # 仅列出将要生成的文件
"""

import importlib.util
import sys
from pathlib import Path

CIRCUITS_DIR = Path(__file__).parent / "circuits"


def run_module(module_path: Path):
    """动态加载并执行单个 circuits/*.py 模块（执行其 __main__ 部分）"""
    spec = importlib.util.spec_from_file_location(module_path.stem, module_path)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)


def main():
    dry = "--dry" in sys.argv

    py_files = sorted(CIRCUITS_DIR.glob("*.py"))
    if not py_files:
        print("⚠️  没有找到 circuits/*.py 文件")
        return

    for f in py_files:
        if dry:
            print(f"  → 将执行 {f.name}")
        else:
            print(f"⚡ 生成 {f.name} …")
            run_module(f)

    if not dry:
        print("✅ 全部完成。")


if __name__ == "__main__":
    main()
```

```
# $\S$ 4-5  一些简单的等效规律和公式

## 1. 两电压源串联

![两电压源串联](../assets/circuits/4_5_1_voltage_series.svg)

$n$ 个电压源串联，等效电压为各电压源电压的代数和：

$$
V_{eq} = \sum_{k=1}^n V_{sk}
$$

## 2. 两电压源并联

![两电压源并联](../assets/circuits/4_5_2_voltage_parallel.svg)

只有电压相等的电压源才允许并联，等效电压等于任一电压源的电压：

$$
V_{eq} = V_{s1} = V_{s2}
$$

## 3. 两电流源的并联

![两电流源并联](../assets/circuits/4_5_3_current_parallel.svg)

$n$ 个电流源并联，等效电流为各电流源电流的代数和：

$$
I_{eq} = \sum_{k=1}^n I_{sk}
$$

## 4. 两电流源的串联

![两电流源串联](../assets/circuits/4_5_4_current_series.svg)

只有电流相等的电流源才允许串联，等效电流等于任一电流源的电流：

$$
I_{eq} = I_{s1} = I_{s2}
$$

## 5. 两电阻的串联

![两电阻串联](../assets/circuits/4_5_5_resistors_series.svg)

$n$ 个电阻串联，等效电阻为各电阻之和：

$$
R_{eq} = \sum_{k=1}^n R_k
$$

分压公式：

$$
V_k = \frac{R_k}{R_{eq}}\,V
$$

## 6. 两电阻的并联

![两电阻并联](../assets/circuits/4_5_6_resistors_parallel.svg)

$n$ 个电阻并联，等效电导为各电导之和：

$$
\frac{1}{R_{eq}} = \sum_{k=1}^n \frac{1}{R_k}
$$

特例——两个电阻并联：

$$
R_{eq} = R_1 \parallel R_2 = \frac{R_1 R_2}{R_1 + R_2}
$$

分流公式：

$$
I_k = \frac{G_k}{G_{eq}}\,I = \frac{R_{eq}}{R_k}\,I
$$
```

```
with schemdraw.Drawing():
```

```
with schemdraw.Drawing():
```

# Getting Started¶

## Installation¶

schemdraw can be installed from pip using

```
pip install schemdraw

```

or to include optional `matplotlib` backend dependencies:

```
pip install schemdraw[matplotlib]

```

To allow the SVG drawing Backends to render math expressions, install the optional ziamath dependency with:

```
pip install schemdraw[svgmath]

```

Alternatively, schemdraw can be installed directly by downloading the source and running

```
pip install ./

```

Schemdraw requires Python 3.9 or higher.

## Overview¶

The `schemdraw` module allows for drawing circuit elements. `schemdraw.elements` contains Basic Elements pre-defined for use in a drawing. A common import structure is:

```
import schemdraw
import schemdraw.elements as elm

```

To make a circuit diagram, use a context manager ( with statement) on a `schemdraw.Drawing`. Then any `schemdraw.elements.Element` instances created within the with block added to the drawing:

```
with schemdraw.Drawing():
    elm.Resistor()
    elm.Capacitor()
    elm.Diode()

```

Element placement and other properties are set using a chained method interface, for example:

```
with schemdraw.Drawing():
    elm.Resistor().label('100KΩ')
    elm.Capacitor().down().label('0.1μF', loc='bottom')
    elm.Line().left()
    elm.Ground()
    elm.SourceV().up().label('10V')

```

Methods up, down, left, right specify the drawing direction, and label adds text to the element. If not specified, elements reuse the same direction from the previous element, and begin where the previous element ended.

Using the with context manager is a convenience, letting the drawing be displayed and saved upon exiting the with block. Schematics may also be created by assinging the new Drawing instance to a variable and adding elements to the drawing with d.add or d +=, then calling draw() and/or save() to show the drawing:

```
d = schemdraw.Drawing()
d += elm.Resistor()
...
d.draw()
d.save('my_circuit.svg')

```

For full details of placing and stylizing elements, see Placing Elements. and `schemdraw.elements.Element`.

In general, parameters that control **what** is drawn are passed to the element itself, and parameters that control **how** things are drawn are set using chained Element methods. For example, to make a polarized Capacitor, pass polar=True as an argument to Capacitor, but to change the Capacitor’s color, use the .color() method: elm.Capacitor(polar=True).color(‘red’).

## Viewing the Drawing¶

### Jupyter¶

When run in a Jupyter notebook, the schematic will be drawn to the cell output after the with block is exited. If your schematics pop up in an external window, and you are using the Matplotlib backend, set Matplotlib to inline mode before importing schemdraw:

```
%matplotlib inline

```

For best results when viewing circuits in the notebook, use a vector figure format, such as svg before importing schemdraw:

```
%config InlineBackend.figure_format = 'svg'

```

### Python Scripts and GUI/Web apps¶

If run as a Python script, the schematic will be opened in a pop-up window after the with block exits. Add the show=False option when creating the Drawing to suppress the window from appearing.

```
with schemdraw.Drawing(show=False) as d:
    ...

```

The raw image data as a bytes array can be obtained by calling .get_imagedata() with the after the with block exits. This can be useful for integrating schemdraw into an existing GUI or web application.

```
with schemdraw.Drawing() as drawing:
    ...
image_bytes = drawing.get_imagedata('svg')

```

### Headless Servers¶

When running on a server, sometimes there is no display available. The code may attempt to open the GUI preview window and fail. In these cases, try setting the Matplotlib backend to a non-GUI option. Before importing schemdraw, add these lines to use the Agg backend which does not have a GUI. Then get the drawing using d.get_imagedata(), or d.save() to get the image.

```
import matplotlib
matplotlib.use('Agg') # Set Matplotlib's backend here

```

Alternatively, use Schemdraw’s SVG backend (see Backends).

## Saving Drawings¶

To save the schematic to a file, add the file parameter when setting up the Drawing. The image type is determined from the file extension. Options include svg, eps, png, pdf, and jpg when using the Matplotlib backend, and svg when using the SVG backend. A vector format such as svg is recommended for best image quality.

```
with schemdraw.Drawing(file='my_circuit.svg') as d:
    ...

```

The Drawing may also be saved using with the `schemdraw.Drawing.save()` method.

## Infinite Transmission Line¶

Elements can be added inside for-loops if you need multiples. The ellipsis is just another circuit element, called DotDotDot since Ellipsis is a reserved keyword in Python. This also demonstrates the `schemdraw.elements.ElementDrawing` class to merge multiple elements into a single definition.

```
with schemdraw.Drawing(show=False) as d1:
    elm.Resistor()
    with d1.hold():
        elm.Capacitor().down()
        elm.Line().left()

with schemdraw.Drawing() as d2:
    for i in range(3):
        elm.ElementDrawing(d1)

    with d2.hold():
        elm.Line().length(d2.unit/6)
        elm.DotDotDot()
        elm.ElementDrawing(d1)
    d2.move(dy=-d2.unit)
    elm.Line().right(d2.unit/6)
    elm.DotDotDot()

```

## 5-transistor Operational Transconductance Amplifer (OTA)¶

Note the use of current labels to show the bias currents.

```
with schemdraw.Drawing() as d:
    # tail transistor
    Q1 = elm.AnalogNFet().anchor('source').theta(0).reverse()
    elm.Line().down(0.5)
    ground = d.here
    elm.Ground()

    # input pair
    elm.Line().left(1).at(Q1.drain)
    Q2 = elm.AnalogNFet().anchor('source').theta(0).reverse()

    elm.Dot().at(Q1.drain)
    elm.Line().right(1)
    Q3 = elm.AnalogNFet().anchor('source').theta(0)

    # current mirror
    Q4 = elm.AnalogPFet().anchor('drain').at(Q2.drain).theta(0)
    Q5 = elm.AnalogPFet().anchor('drain').at(Q3.drain).theta(0).reverse()

    elm.Line().right().at(Q4.gate).to(Q5.gate)

    elm.Dot().at(0.5*(Q4.gate + Q5.gate))
    elm.Line().down().toy(Q4.drain)
    elm.Line().left().tox(Q4.drain)
    elm.Dot()

    # vcc connection
    elm.Line().right().at(Q4.source).to(Q5.source)
    elm.Dot().at(0.5*(Q4.source + Q5.source))
    elm.Vdd()

    # bias source
    elm.Line().left(0.25).at(Q1.gate)
    elm.SourceV().down().toy(ground).reverse().scale(0.5).label("Bias")
    elm.Ground()

    # signal labels
    elm.Tag().at(Q2.gate).label("In+").left()
    elm.Tag().at(Q3.gate).label("In−").right()
    elm.Dot().at(Q3.drain)
    elm.Line().right().tox(Q3.gate)
    elm.Tag().right().label("Out").reverse()

    # bias currents
    elm.CurrentLabel(length=1.25, ofst=0.25).at(Q1).label("20µA")
    elm.CurrentLabel(length=1.25, ofst=0.25).at(Q4).label("10µA")
    elm.CurrentLabel(length=1.25, ofst=0.25).at(Q5).label("10µA")
```

## 二、核心概念速查

### 2.1 方向控制

每个元件从上一个元件的终点开始，沿指定方向画：

```python
elm.Resistor().right()    # 向右
elm.Capacitor().down()    # 向下
elm.Line().up()           # 向上
elm.Battery().left()      # 向左
```

不指定方向时，沿用上一个元件的方向。

### 2.2 定位方法

| 方法 | 作用 | 示例 |
|------|------|------|
| `.at(pos)` | 从指定位置开始画 | `.at(R1.end)` |
| `.to(pos)` | 画到指定位置 | `.to(V1.start)` |
| `.tox(pos)` | 画到与某个点同样的 x 坐标 | `.tox(V1.start)` |
| `.toy(pos)` | 画到与某个点同样的 y 坐标 | `.toy(V1.start)` |
| `.endpoints(a, b)` | 指定起点和终点 | `.endpoints(C1.end, C5.start)` |
| `.anchor(name)` | 从某个锚点开始 | `.anchor('collector')` |
| `.reverse()` | 翻转元件方向 | `.reverse()` |
| `.flip()` | 镜像翻转 | `.flip()` |
| `.shift(dx, dy)` | 微调位置 | `.shift(0.3)` |

### 2.3 push / pop（分支）

```python
d += elm.Resistor().right()   # 主路
d.push()                       # 记住当前位置
d += elm.Line().down()         # 回到分叉点往下画
d += elm.Resistor().right()
d += elm.Line().up()
d.pop()                        # 回到主路
```

这是画并联结构的基础。

### 2.4 标签

```python
elm.Resistor().label('$R_1$')                # 默认位置上标签
elm.Resistor().label('$v_o$', loc='bot')     # 底部标签
elm.Resistor().label('$R$', loc='center')    # 居中标签
elm.Resistor().label(['+', '$v$', '-'])      # 多行标签
elm.Dot().label('a', 'left')                 # 节点标签
```

`loc` 可选：`'top'`, `'bot'`, `'left'`, `'right'`, `'center'`, `'lft'`, `'rgt'`

### 2.5 样式

```python
d.config(fontsize=12, unit=3)                 # 全局字体和单位长度
elm.Resistor().color('red')                   # 颜色
elm.Resistor().linewidth(3)                   # 线宽
elm.Resistor().linestyle('--')                # 虚线
elm.Resistor().scale(1.5)                     # 缩放
elm.Line().length(2)                          # 线长（单位数）
```

`unit` 控制元件两端引线的长度，`length` 控制 Line 的总长度。

### 2.6 节点与连接点

```python
elm.Dot()            # 实心连接点
elm.Dot(open=True)   # 空心点（端子）
elm.Ground()         # 接地
elm.Ground(lead=False)  # 无引线接地
elm.Vdd()            # 电源
elm.Vss()            # 地
```

## 四、画出更好电路图的技巧

### 4.1 先设计布局再写代码

在纸上或脑中画好草稿，明确：
- 主回路在哪（一般是矩形）
- 哪些元件在水平方向，哪些在垂直方向
- 并联分支从哪分叉、哪汇合

### 4.2 用 `push/pop` 画并联

我帮你画的 `4_5_6`（两电阻并联）就是这样做的：

```python
d += elm.Resistor().right().label("$R_1$")   # 上分支
d.push()
d += elm.Line().down()
d += elm.Resistor().right().label("$R_2$")   # 下分支
d += elm.Line().up()
d.pop()
```

### 4.3 用 `tox` / `toy` 画闭合回路

不必手动算坐标，让元件自动对齐到另一个元件的 x 或 y：

```python
elm.Line().tox(V1.start)   # 水平对齐到 V1 的起点
elm.Line().toy(V1.end)     # 垂直对齐到 V1 的终点
```

### 4.4 用 `at` 和锚点画复杂电路

```python
# 从某个元件的特定锚点开始画
elm.Line().at(opamp.out).right()
elm.Resistor().at(Q1.collector).up()
```

### 4.5 善用 `hold()`

```python
with d.hold():      # 括号内的所有画图操作不影响当前光标
    ...
```

用于画一组相对独立的子电路。

### 4.6 给元件分组复用

同一个模式多次出现时，先画一次存为 `ElementDrawing`，再复用：

```python
with Drawing(show=False) as pattern:
    elm.Resistor()
    elm.Capacitor().down()
    elm.Line().left()

# 在正式图里重复使用
for i in range(3):
    elm.ElementDrawing(pattern)
```

## 五、针对你的项目的建议

你的电路分析笔记主要有这几类图，对应的最佳画法：

| 图的类型 | 推荐画法 |
|----------|---------|
| 单个等效规律（如 §4-5） | push/pop + 简单矩形回路 |
| 戴维南/诺顿等效 | 左边画原始电路，右边画等效电路，中间加 `⇒` 箭头 |
| 网孔分析 | 用 `LoopCurrent` 标注网孔电流 |
| 节点分析 | 用 `Dot` + 标签标明节点电压 |
| 运放电路 | 用 `Opamp` 元件 + 反馈路径 |
| 一阶/二阶动态电路 | 电阻 + 电容/电感 + 开关 (`Switch`) |
| 相量图 | 不适合 Schemdraw，建议单独用 TikZ 或手绘 |

## 六、即时查阅 API

在终端随时查元件用法：

```bash
# 列出所有可用元件
python3 -c "import schemdraw.elements as elm; print([x for x in dir(elm) if not x.startswith('_')])"

# 查看元件有哪些方法
python3 -c "import schemdraw.elements as elm; print([m for m in dir(elm.Resistor) if not m.startswith('_')])"

# 快速预览某个画法
python3 -c "
import schemdraw, schemdraw.elements as elm
d = schemdraw.Drawing()
d += elm.Resistor().right().label('R1')
d += elm.Capacitor().down().label('C1')
d += elm.Line().left()
d += elm.SourceV().up().label('Vs')
d.save('/tmp/test.svg')
print('saved to /tmp/test.svg')
"
```

最后强烈建议多浏览 **Analog Gallery** 页面（<https://schemdraw.readthedocs.io/en/latest/gallery/analog.html>），里面有 20+ 个实际电路的完整例程，覆盖了电源、运放、BJT、LoopCurrent、变压器等常见场景，是学画法最好的范本。
