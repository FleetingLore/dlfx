电流
电荷
: 粒子所带电荷的多少称为电荷量
  带电粒子的有秩序的移动形成电流

电流的方向
= 电流的方向是正电荷的移动方向

电流的大小
= 每单位时间内通过导体横截面的电荷量
  i (t)
  {_d_ q}/{_d_ t}

电流的可变性 {
  恒定电流
  : 电流的大小和方向不随时间变化
    简称直流
    记作 dc 或 DC
    可用 I 表示

  时变电流
}

交变电流
: 时变电流的大小和方向都随时间作周期性变化
  简称交流
  简写为 ac 或 AC

电压
电流的能量效应
: 电荷在电路的流动有能量交换发生
  电荷可以在一些地方获得能量或失去能量
  能量可以流入或流出电路

电压的值
= 两点间电压的大小
  单位正电荷转移时获得或失去的能量
  u (t)
  {_d_ w}/{_d_ q}

电压的方向 {
  正电荷从负极到正极
  = 电压升 {
    获得能量
  }
}
