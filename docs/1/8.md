# $\S$ 1-8  分压公式和分流公式

## 1. 串联电阻电路

### 1.1  简单情形

$$u_1 = \frac{R_1}{R_1 + R_2}$$

$$u_2 = \frac{R_2}{R_1 + R_2}$$

### 1.2  一般情形

$$u_i = \frac{R_i}{\displaystyle \sum _{j = 1} ^{n} R_j} u$$

### 2. 并联电阻电路

#### 2.1 简单情形

$$i_1 = \frac{G_1}{G_1 + G_2}$$

$$i_2 = \frac{G_2}{G_1 + G_2}$$

#### 2.2 一般情形

$$i_i = \frac{G_i}{\displaystyle \sum _{j = 1} ^{n} G_j} i$$
