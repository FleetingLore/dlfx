  习惯上 {
    将电阻元件称作电阻 {
      一般指具有正实常数 R 的线性正电阻
    }
  }

线性与非线性

    很多实际器件可以采用线性元件建模
  }

特性曲线与时间的关系
: 时变的 : 特性曲线不关于时间变化
  时不变的 : 特性曲线与时间有关

调转电压方向
: 单向性 : 调转电压方向后行为不同
  双向性 : 行为关于原点对称
