线性电导和电流源
自电导
: 连接于各个节点的元件的电导的总和.

互电导
: 下标两节点间元件的电导总和的负值
  符号来自电压下降的默认

电流源电导 {
  不计
}

流程
: 求各个节点的自电导、互电导
  根据参考节点列节点电压方程
  解方程,得到节点电压
